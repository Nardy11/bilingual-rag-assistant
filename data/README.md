# Sample corpus

Five short documents of **Falak Home Systems, a fictional company** invented for this project. All of them were
written for this repository and are released under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Any resemblance to a real company is accidental.

| File | Language | Format | Content |
|---|---|---|---|
| `corpus/employee-handbook.en.md` | English | Markdown | HR policy: hours, leave, probation, remote work, expenses, training |
| `corpus/travel-policy.en.pdf` | English | PDF, 2 pages | Business travel: booking, flights, hotels, per diem, insurance |
| `corpus/shipping-and-returns.en.txt` | English | plain text | Delivery areas, fees, returns, refunds |
| `corpus/product-faq.ar.md` | Arabic | Markdown | FAQ for the "Falak Pure 300" water filter |
| `corpus/it-security-policy.ar.md` | Arabic | Markdown | IT security policy for employees |

The PDF is generated from `scripts/make_sample_pdf.py` (reportlab).
