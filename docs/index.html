Bilingual RAG Assistant مساعد المستندات

Ask in Arabic or English about the documents of Falak Home Systems, a fictional company: HR handbook, travel policy, shipping terms, IT security policy and a product FAQ. Search and answers run entirely in your browser, with no server and no API key. Answers come within a second; the translation and re-ranking models (about 340 MB) then load in the background for better cross-language answers (about 3 s each).

Loading the multilingual embedding model (about 120 MB, cached after the first visit)…

Retrieved passages hybrid search: embeddings + BM25 for the question and its translation, fused with reciprocal rank fusion, then re-ranked by a cross-encoder

    Model: Xenova/multilingual-e5-small (8-bit ONNX) via transformers.js. The document index was precomputed in Python with the same model. This demo uses the extractive answerer: it quotes the best supporting sentences and cites them. The Python service can generate answers with Gemini or any OpenAI-compatible model instead.
